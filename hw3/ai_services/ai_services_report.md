# AI-сервисы: отчет о проверке

## Цель

Проверить инструменты Cursor, Claude Code, VSCode с AI-плагинами и локальную
Gemma, а также сравнить, ходят ли модели в интернет и насколько активно.

## Проверенные инструменты

| Инструмент | Что проверялось | Интернет/API | Наблюдение |
|---|---|---|---|
| Cursor | Открытие проекта, чат по коду, запрос актуальной версии Spark | Да, облачная модель; web search включается явно через web-инструменты / `@Web` | Хорошо использует контекст проекта, интернет активен при явной просьбе найти свежую информацию |
| Claude Code | CLI-агент в терминале, чтение файлов, запуск команд | Да, требуется Anthropic cloud/API; локальные shell-команды выполняются с разрешения пользователя | Сильный агент для проекта; интернет не является локальной моделью, внешняя сеть нужна для самого Claude |
| VSCode + AI-плагины | GitHub Copilot Chat/Agent, подсказки, работа с файлами | Да, нужен аккаунт/облачный сервис; web/fetch tools зависят от настроек | Удобен для автодополнения и небольших правок; web-доступ менее агрессивный, чем у dedicated web search |
| Gemma через Ollama | Локальный запуск `gemma3`, ответы без облака | После загрузки модели может работать без интернета | В интернет сама не ходит; на вопросы про свежие версии может ошибаться без внешнего поиска |

## Команды и шаги проверки

### Cursor

1. Установлен Cursor с официального сайта.
2. Открыт проект с Docker/Spark-файлами.
3. Проверены два режима:
   - вопрос по локальному коду;
   - вопрос про свежую версию Spark с просьбой сослаться на источник.

Результат: по локальному коду Cursor использует индекс проекта; для свежей
информации нужен web search. Без web search ответы выглядят как ответы из
памяти модели.

### Claude Code

1. Проверен запуск CLI.
2. Проверены команды чтения файлов проекта и объяснения `docker-compose.yml`.
3. Проверен запрос на свежую информацию.

Результат: Claude Code является облачным AI-агентом, поэтому для генерации
ответов нужен доступ к сервису Claude. Для интернет-поиска он не является
локальной автономной моделью; активность зависит от доступных инструментов и
разрешений.

### VSCode + AI-плагины

1. Проверены Copilot Chat / Agent mode.
2. Проверен запрос по локальному файлу.
3. Проверен запрос, требующий актуальной информации.

Результат: для AI-функций нужен облачный сервис. Доступ к внешнему web/fetch
инструменту зависит от настроек расширения и политики workspace.

### Gemma локально

Команды:

```bash
ollama pull gemma3:4b
ollama run gemma3:4b "Explain what Apache Spark does in two sentences"
```

Результат: после загрузки модели ответы генерируются локально. Если отключить
интернет, модель продолжает отвечать, но не может проверять свежие факты.

## Вывод

Cursor, Claude Code и VSCode AI-плагины зависят от облачных API. Они удобны для
работы с кодом и могут использовать интернет или внешние инструменты, если это
разрешено настройками. Gemma через Ollama принципиально отличается: это
локальный inference, который после загрузки модели не ходит в интернет и не
может сам проверять актуальные данные.
